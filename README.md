# Intermodular-SISTEMAS

En el apartado de sistemas, se explica cómo instalar un sistema operativo correctamente, teniendo en cuenta la creación de usuarios, grupos y la asignación de permisos.
Seguidamente, se añaden los usuarios a los grupos a los que corresponden, como por ejemplo, un usuario de desarrollador al grupo de Desarrolladores.
También, se tiene en cuenta la seguridad básica de un equipo y los métodos más recomendables para llevarla a cabo.
Por lo tanto, primeramente he instalado Windows 11 configurando así todo lo necesario como el nombre del equipo, conexión a Internet...
Después, he actualizado el sistema con Windows Update y he descargado algunas de las aplicaciones necesarias para los trabajadores.
Por último, he activado el BitLocker y el Windows Defender.
